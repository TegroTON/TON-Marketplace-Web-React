A **React** web frontend prototype for the **NFT marketplace on TON**, part of the Libermall marketplace experiments.

## Overview
An early React web interface for the marketplace (see also the later iteration [TON-Marketplace-Update-React](https://github.com/TegroTON/TON-Marketplace-Update-React) and the Kotlin/JS variant [TON-Marketplace-NFT-Web](https://github.com/TegroTON/TON-Marketplace-NFT-Web)).

## Tech Stack
- **Framework:** React + TypeScript (ESLint)
- **TON connectivity:** TON Connect
- **Styling:** Bootstrap, Slick
